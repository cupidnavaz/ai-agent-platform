# Project Charter

## Purpose

Build a maintainable AI engineering platform rather than a simple chatbot.

---

## Principles

- Architecture before features
- Documentation alongside code
- Small iterative improvements
- High code quality
- Provider independence
- Extensibility
- Testability

---

## Engineering Rules

Every sprint must include:

- implementation
- testing
- documentation updates
- meaningful commit

Every milestone must include:

- git tag
- changelog update
- architecture review

---

## Definition of Done

A feature is complete only when:

- code works
- tests pass
- documentation updated
- committed to git
