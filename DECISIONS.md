# Architecture Decisions Index

This file provides a high-level overview of major engineering decisions.

## Accepted

001 Runtime-Centered Architecture

- Runtime coordinates the platform.

002 Dependency Injection

- Dependencies are supplied through a container.

003 Provider Independence

- Runtime never depends on a specific AI provider.

004 Documentation First

- Documentation evolves alongside the code.

005 Modular Components

- Agents
- Providers
- Tools
- Memory
- Plugins remain independent.
