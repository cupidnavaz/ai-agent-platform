# Project Glossary

## Runtime

Coordinates the platform.

---

## Agent

Makes decisions using providers, memory, and tools.

---

## Provider

Communicates with AI models.

---

## Tool

Performs external actions.

---

## Memory

Stores conversational context.

---

## Storage

Persists data beyond runtime memory.

---

## Session

Represents one active interaction.

---

## Plugin

Extends platform functionality.
